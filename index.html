Core Capabilities

核心 AI 辨識能力

針對道路養護與路口標線巡查需求設計的四大自動化分析模組。

01. 斑馬線偵測

自動定位畫面中行人穿越道（crosswalk）的邊界框位置，並以非極大值抑制（NMS）過濾重疊候選框。

02. 標線狀態分析

針對最高信心斑馬線原圖區域進行灰階直方圖統計，量化評估漆面反差清晰度與環境照明能見度。

03. 駕駛視角空間評估

計算標線框底邊距離與垂直高度佔比，判讀行車記錄器視角下是否存在視線盲區或近距離空間壓迫。

04. 風險分級報告

彙整五項指標計算 0 至 7 分風險總分，對應低、中、高風險等級，並自動生成具體養護與通行建議。

畫面標註圖例： 綠色外框（#00FF00）：偵測到的斑馬線（crosswalk） 標籤百分比（如 crosswalk 88%）：模型判定為斑馬線的信心程度
Evaluation Standards

評估標準與風險分級

當畫面偵測到多條斑馬線時，系統自動鎖定信心程度最高的一條進行像素與幾何分析。註：以下各項判定門檻為教學與巡檢示範暫定值。

評估指標 計算方式 0 分（正常） 1 分（注意） 2 分（異常） 適用範圍
1. 標線清晰度 框內灰階第 90 百分位 − 第 10 百分位（256 格直方圖） ≥ 80 50 ~ 80 < 50 通用視角
2. 框內能見度 框內像素平均灰階值（0.299R + 0.587G + 0.114B） 70 ~ 200 40 ~ 70 或 200 ~ 230 < 40 或 > 230 通用視角
3. 完整度 框任一側距影像邊緣小於對應圖寬或圖高的 2% 四邊皆 ≥ 2% 任一側 < 2%（記錄貼邊側） — 通用視角
4. 視線盲區 底邊距離比例 = (圖高 − (y + h)) / 圖高 ≥ 0.18 < 0.18 — 限駕駛視角
5. 空間壓迫 高度佔比 = h / 圖高 ≤ 0.25 > 0.25 — 限駕駛視角
綜合風險分級（總分 0 ~ 7 分）： ≤ 1 分：低風險（#2e7d32） 2 ~ 3 分：中風險（#ef6c00） ≥ 4 分：高風險（#c62828） 未偵測到斑馬線：無法評估（#616161）
Detection Scenarios

交通風險與辨識場景對照

不同道路實體狀況與拍攝條件下，系統的指標觸發機制與判讀結果。

風險類別 辨識場景 偵測方式與結果
標線褪色或磨損 白色熱拌漆長期輾壓剝落、柏油與標線色差不足 計算框內灰階 P90−P10 對比度，低於 80 依程度計 1~2 分並提示補繪
光線過暗或過曝 夜間路燈昏暗、隧道出口逆光或正午強光反射 計算框內平均灰階，偏離 70~200 區間依程度計 1~2 分
斑馬線被切掉或遮住 拍攝距離過近或角度偏斜導致標線超出畫面邊界 偵測框任一邊距圖緣小於 2%，計 1 分並標明貼邊方向
視線盲區 駕駛視角下斑馬線過於貼近車頭前緣底部 底邊距離比例小於 0.18，計 1 分並提醒前緣視線死角風險
空間壓迫 車輛逼近路口或廣角畸變使標線垂直佔比過大 框高度佔圖高大於 0.25，計 1 分並提示預留緩衝煞車距離
綜合分級 單一或多重道路硬體與視角異常同時發生 加總五項得分（0~7 分），映射至低、中、高三級風險標籤
未偵測到斑馬線 標線完全磨滅、遭大型車輛完全遮擋或非路口畫面 信心值皆低於 0.4，顯示「無法評估」並建議確認現場或重拍
System Boundaries

目前尚未支援功能說明

本系統專注於「靜態道路硬體（斑馬線）」之單張影像幾何與像素評估，下列項目不在目前模型辨識範圍內：
  • 紅綠燈號誌位置與燈號顏色（紅燈、黃燈、綠燈）辨識
  • 行人、汽車、機車等動態用路人偵測與軌跡追蹤
  • 路口未禮讓行人、闖紅燈等動態交通違規舉發
  • 紅黃線違規停車或併排停車判定
  • 機車騎士未戴安全帽等行為類違規偵測

※ 上述物件與行為類偵測，需另行擴充資料集標註對應類別並重新訓練多類別模型後方可支援。

Architecture & Features

模型開發流程與系統技術特色

從資料標註到瀏覽器端邊緣推論的完整實作管線；開發人員可直接修改程式最上方的門檻常數調整評估靈敏度。

1

Roboflow 影像標註

收集街景與行車記錄器畫面，標註 crosswalk 邊界框並進行資料增強。

2

Google Colab 訓練

使用 Ultralytics YOLO26n 架構訓練輕量化目標偵測權重。

3

匯出 ONNX 格式

將訓練完成之模型轉換為標準 best.onnx（輸入 640×640）。

4

前端即時推論

透過 ONNX Runtime Web 執行前處理、推論、NMS 與像素風險評估。

純地端推論（照片不上傳）

模型直接下載至瀏覽器記憶體運作，巡檢照片無須傳送至外部伺服器，兼顧資安與隱私。

YOLO 空間標定

採用等比例 Letterbox 縮放補灰邊，推論後精準還原至原圖座標並執行單類別 NMS 過濾。

像素分析與評分決策引擎

直接從未加框原圖裁切最高信心標線區域，計算灰階直方圖分位數與空間比例產出報告。
